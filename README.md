# Vocabulary Self-study Room

A browser-based English vocabulary study app. Import a CSV/TSV list, reveal translations, sort words into study states, review with randomized cards, practice spelling from Chinese prompts, edit entries, and delete one or many words. Vocabulary is stored locally in the learner's browser.

## Publish with GitHub Pages

This repository includes a Pages workflow. In **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. Pushes to `main` will then publish the site.
